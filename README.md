# 日払い給与計算

仲居・ドライバーの日払い給与を、その場で計算して記録するブラウザアプリです。
インストール不要で、GitHub Pages に置くだけでスマホから使えます。

## できること

- **仲居**：出勤・退勤の時刻から、時間帯ごとに時給を分けて計算
  - 研修中　〜22時 1,250円／22時〜 1,600円
  - 研修後　〜22時 1,300円／22時〜 1,650円／0時〜 1,650円＋1時間あたり手当100円
  - 休憩（はじめ・おわり）を入れると、その時間を差し引きます
  - 0時をまたぐ勤務は、出勤した日の記録になります（0時〜5時の入力は前日の営業日扱い）
- **ドライバー**：お迎え（早出のみ 2,800円／遅出のみ 2,800円／早出＋遅出 5,600円）と送り（深夜 4,600円）
- **加算・差し引き**：交通費や手当の加算、駐車場代・お弁当代・その他の差し引き
- **日払い**：1日1人ずつ支払額を出し、封筒に入れる金種（お札・硬貨の枚数）も表示
- **記録**：日別の支払い合計と未払い、支払済の「済」印、月別のスタッフごとの集計、CSV書き出し
- **明細を送る**：スマホなら LINE などにそのまま送れます
- **シークレットログイン**：ロック中は時計だけの画面。時計を5回続けてタップ（または長押し）するとパスコード入力が出ます
- 単価・差し引き項目・スタッフは、アプリの［設定］［スタッフ］から変えられます

1円未満は行ごとに四捨五入しています。

## ファイル

| ファイル | 役割 |
| --- | --- |
| `index.html` | アプリ本体（画面・計算・ロックがすべて入っています） |
| `manifest.webmanifest` | ホーム画面に追加したときの名前とアイコン |
| `sw.js` | 電波がないときも開けるようにする仕組み |
| `icon-192.png` ほか `.png` | アイコン画像 |

## GitHub Pages で公開する（ブラウザだけでできます）

1. [GitHub](https://github.com/) で無料アカウントを作ります。
2. 右上の「＋」→「New repository」を押します。
   - Repository name：好きな名前（例：`hibarai`）
   - **Public** を選びます（無料プランで Pages を使うには公開リポジトリが必要です）
   - 「Create repository」を押します。
3. 次の画面の「uploading an existing file」を押し、zip を展開した中身（8つのファイル）をすべてアップロードして、「Commit changes」を押します。
   - パソコン：ファイルをまとめてドラッグします。
   - iPhone：「choose your files」→「ファイルを選択」→ 展開したフォルダを開き、右上の「選択」で8つとも選んで「開く」。
4. リポジトリの「Settings」→ 左の「Pages」を開きます。
   - Source：**Deploy from a branch**
   - Branch：**main**、フォルダは **/(root)** を選んで「Save」
5. 1〜2分待つと、`https://（ユーザー名）.github.io/hibarai/` で開けるようになります。

## スマホのホーム画面に追加する

- **iPhone**：Safari で開く → 共有ボタン →「ホーム画面に追加」
- **Android**：Chrome で開く → 右上の︙ →「ホーム画面に追加」または「アプリをインストール」

iPhone では、**必ずホーム画面に追加して使ってください。**
Safari のまま使うと、7日間開かなかったときにデータが消されることがあります（Safari の仕様です）。

## はじめて開いたとき

1. パスコードを決めます（4文字以上。6桁以上がおすすめ）。
2. 「シークレットログインを使う」をオンにすると、次からは時計の画面が出ます。
   時計を5回続けてタップするか長押しすると、パスコードの入力欄が出ます。
3. ［設定］で、駐車場代・お弁当代の金額を入れておくと、1回のタップで差し引けます。
4. ［スタッフ］に登録すると、名前をタップするだけで職種・研修中かどうか・いつもの差し引きが入ります。

## 大事な注意

- **データは端末ごとに保存されます。** スマホとパソコンなど、別の端末とは共有されません。
  記録はパスコードで暗号化して、その端末のブラウザの中だけに保存しています（GitHub には送られません）。
- **パスコードを忘れると、データは取り出せません。** ［設定］→「バックアップを保存」で、月に1回くらいバックアップを取ってください。
  バックアップを戻すときは、バックアップを作ったときのパスコードが必要です。
- **ブラウザの「履歴とデータの削除」をすると、記録も消えます。**
- 公開リポジトリなので、アプリのプログラム（最初に入っている単価を含む）は誰でも見られます。
  入力した記録・スタッフ名・変更した単価は端末の中にだけあるので、見られません。
  最初の単価も見せたくない場合は、`index.html` の `DEFAULT_SETTINGS` の金額を 0 にしてからアップロードし、アプリの［設定］で入力してください。
- 検索エンジンに載らない設定（noindex）にしてあります。

## 単価や名前を変えたいとき

- **単価**：アプリの［設定］→「給与の単価」で変えられます。保存済みの記録は、保存したときの単価のまま残ります。
- **最初に入っている単価**：`index.html` の中の `DEFAULT_SETTINGS` を書き換えます。
- **ホーム画面に出る名前**：`manifest.webmanifest` の `name`・`short_name` と、`index.html` の `apple-mobile-web-app-title` を書き換えます。
  目立たない名前（例：「メモ」）にすることもできます。

## 更新するとき

GitHub のリポジトリで `index.html` を開き、新しいファイルをアップロードして上書きします。
`sw.js` の `CACHE = 'hibarai-v1'` の数字を1つ上げてから一緒にアップロードすると、スマホ側でも確実に新しい版に切り替わります。
記録は端末に残っているので、更新しても消えません。
